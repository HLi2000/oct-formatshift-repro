# OCT-FormatShift — VLM4RWD paper (self-contained LaTeX project)

Submission-ready NeurIPS-style paper: *When the Scanner Changes: Calibrated, Decision-Level Reliability of
Frontier VLMs and Foundation Models for Glaucoma Triage.* This directory is **self-contained** — it carries its own
style files, bibliography, and figures, so it can be zipped or split into its own repo without the rest of the
monorepo.

## Build locally
```bash
tectonic main.tex          # -> main.pdf  (first run downloads the TeX bundle)
# or: make
```
Body is 8 pp (title→conclusion); references + appendix + the full NeurIPS checklist follow. Double-blind workshop
mode via `\usepackage[dblblindworkshop, nonatbib]{neurips_2026}` (line numbers, "Anonymous Author(s)"). For
camera-ready, de-anonymize the author block in `main.tex` and switch to the final style option.

## Import into Overleaf
Overleaf's *Import from GitHub* pulls a **whole repo**, and this paper lives inside the larger `Glaucoma-Triage`
monorepo, so point Overleaf at the paper, not the monorepo, via one of:
1. **Zip upload (simplest, no GitHub):** zip this directory and use Overleaf → *New Project → Upload Project*.
   ```bash
   cd .. && zip -r oct-formatshift-vlm4rwd.zip oct-formatshift-vlm4rwd \
     -x '*.aux' '*.log' '*.out' '*.bbl' '*.blg' '*.pdf'
   ```
2. **Standalone repo (for Overleaf↔GitHub sync):** push just this directory to its own empty GitHub repo, then
   Overleaf → *New Project → Import from GitHub*.

## Files
- `main.tex` — preamble + document skeleton (inputs the parts below)
- `sections.tex` — abstract → conclusion
- `table1.tex` — headline arms, both axes (hand-curated subset)
- `appendix.tex` + `appendix_tables.tex` — setup, shift validity, full 29-arm tables, repro + impact
- `references.bib` — verified bibliography (see `REFERENCES_VERIFICATION.md`)
- `figures/` — vector PDFs, regenerated by `scripts/build_paper_submission_figures.py` and
  `scripts/build_paper_tables.py` (repo root); no re-scoring, driven by the committed `reports/oct_*_panel.json`
- `neurips_2026.sty`, `extra_pkgs.tex`, `checklist.tex`, `Makefile` — style, NeurIPS paper checklist, build

## Reproducibility
Three tiers, cheapest first. All *numbers* reproduce at tier 1; the figure *images* additionally need tier 2/3.

**1. Every number (all tables + the scatter/ρ values in Fig 3).** From the committed `reports/*.json` panels
alone, no data download:
```bash
cd ../.. && .venv/bin/python scripts/build_paper_tables.py       # all tables
.venv/bin/python scripts/build_paper_submission_figures.py       # scatter/ρ read from shift_mechanism.json
```

**2. The npz-backed figures (Fig 3 flip-direction column, Fig A3 reliability).** Need the per-eye contender
`*_contender.npz`. The frontier-VLM npz are committed under `data/derived/` and `data/derived/map_fm/`; the
larger foundation-model / CNN npz are ~270 MB and are fetched + checksum-verified from the authors' cache:
```bash
GH_TOKEN=... .venv/bin/python scripts/fetch_oct_data.py oct_contender_npz.tar   # then: tar -xf into data/derived/
```
VLM npz alone are not enough for these two figures — the FM/CNN npz are required.

**3. The raw-image figures (Fig 1, A1/A2) + regenerating the panels from scratch.** Need the source datasets
under `data/raw/` (public / registered-access; not redistributed here):
- **Harvard-GDP** (thickness-map axis) — `scripts/download_harvard_gdp.py` (HuggingFace `harvardairobotics/Harvard-GDP`, CC BY-NC-ND 4.0).
- **GLEAM** (Spectralis B-scan axis) — single-center; available on request.
- **GOALS** (cross-vendor Topcon validity) — MICCAI-2022, Baidu AI Studio competition/230 (grand-challenge iChallenge-GON3).
- **RETOUCH** (speckle calibration) — MICCAI-2017, `retouch.grand-challenge.org`.

Then re-run the panel builders (`scripts/run_oct_*_panel.py`, `compute_*`, `analyze_*`). The large binaries in
tiers 2–3 are pinned by `reports/oct_format_data_manifest.json` (name + SHA256 + size); `fetch_oct_data.py`
verifies each download against it.
